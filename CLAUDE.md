# Ground Observer, 1957 (fork of Abyssal Garden)

A first-person night walk in a fictional 1957 desert canyon, rendered with WebGPU, everything generated by code,
built into one self-contained `index.html`.

**Read `PLAN.md` first, all of it.** Section 0 says where the work stands, what the owner decided after the plan was
written, and how to build, run and test. Sections 2, 6 and 8 hold the decisions, the scope and the hooks for later.

Rules that matter most:
- The owner is a hobby game designer, not an engineer. Explain in plain words. Work milestone by milestone and stop
  for their review. Don't make creative decisions that aren't in `PLAN.md`; ask.
- Period rule: nothing in the game world that didn't exist in 1957.
- Don't change the owner's night-look values (`LOOK_OWN` in `source/src/main.js`). Don't draw a hand, arm or body.
- Test in the HEADLESS Chrome from `C:\Users\Bacon\abyssal_tools\README.txt`. Never bring a test window to the front.
- When a critic's reading conflicts with what the owner describes, ask the owner for screenshots.
- Keep one HTML file with no libraries or asset files, and allocate nothing per frame.
- Build with `cd source && node build.mjs` (and `--dev` for `dev.html`). Commit `index.html` with the source changes.
  Commit small, with plain-language messages. Don't push unless asked.
