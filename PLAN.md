# PLAN: retheme Abyssal Garden into a 1950s desert-night horror walk

Read this whole file before touching code. It started as the handoff from a planning chat with the owner;
section 0 says where the work stands now and how to pick it up.
The owner is a hobby game designer, not an engineer: explain technical choices in plain terms, and show
them each milestone running before starting the next.

Base: fork of Noniv/abyssal-garden (MIT, keep LICENSE and credit upstream in README).
Everything is generated by code, no asset files. Keep it one self-contained `index.html` built from `source/`.
Desktop Chrome first. Phone support must not be broken on purpose, but is not tested until later.

### How a new agent picks up
1. Read this whole file, then `git log --oneline -30` on `m2-walking`. The commit messages explain what changed
   and why, in plain words.
2. **Build:** `cd source`, `npm install` once, then `node build.mjs` writes `index.html` (the game) and
   `node build.mjs --dev` writes `dev.html` (the same game plus the dev tools). Commit `index.html` together with the
   source changes. `dev.html` isn't tracked.
3. **Run and test:** the game needs Chrome with WebGPU, served over http. The test tools live outside the repo, in
   `C:\Users\Bacon\abyssal_tools` (its `README.txt` has the exact commands). `server.mjs` serves this folder on
   port 8791 (8765 is taken by another app). `cdp.mjs` runs JavaScript in the test tab. `shots.mjs final.json` takes
   the 17 fixed critic shots with the free camera. `walkshots.mjs` takes shots in walking mode, lantern in hand.
   `reload.sh` reloads the test tab after a rebuild.
4. **Use the headless test Chrome** (command in the tools README). Never bring a test window to the front: the owner
   types on the main monitor and it steals their focus, and a minimized window stops rendering. When the owner wants
   to try a build, open `http://127.0.0.1:8791/index.html` in their normal Chrome.
5. **Dev build keys:** 1-6 viewpoints, G free camera (Q/E move down and up in it), H stats, T night-look sliders,
   F fly-through, B benchmark, R the ruins' supper stages. In the browser console, the `dev` object
   (`source/src/dev.js`) takes shots, profiles (`dev.freeze(100); dev.res(pix); dev.prof(90, skipBits)`), switches parts
   of the scene off for side-by-side comparisons (`dev.skip(bits)`), teleports (`dev.walkTo(x, z, yaw, pitch)`), sets
   the eclipse clock (`dev.clock(minutes)`) and more.
6. **What the original is up to:** `git fetch upstream` then `git log --oneline main..upstream/main` lists Noniv's
   new commits on Abyssal Garden since this fork. Worth a look for fixes and speed-ups to bring over.
7. **Ask the owner what comes next.** The open choices: keep working down the art critic's list (M3 polish), the
   trailer interior (needs the owner's go-ahead), or start M4 sound. Stop at the end of each milestone for review.

Gotchas that cost time before:
- Mesh ids are positions in the `meshes` array in `main.js` (the list is commented just above it). Keep every slot:
  put `unused()` in a slot you empty, so the ids used in `world.js` and `ruins.js` don't shift. Part ids (the
  material numbers in `prop()` in `shaders.js`) are a separate numbering.
- `dev.view(x, y, z, ...)` takes an absolute height; `shots.mjs` adds the ground height itself.
- Chrome pauses the frame loop in a hidden window, so anything that eases over time must be set instantly for shots
  (`dev.lift` does this for the lantern).
- For a side-by-side comparison, build the other version into a separate page. Never swap source files back and
  forth: an interrupted command once left the tree on the old shader.
- Performance changes must not change the picture: check them with frozen-clock renders (`dev.freeze`) before and
  after, at the same resolution and in the same setup. Timings are only comparable within one setup (headless renders
  at 1966x850).

## 1. The concept

You are a 1950s UFO hobbyist camping alone in Coldsupper Canyon National Monument, a fictional red-rock canyon in the southern California desert, in the last dark hours of 7 November 1957.
You start inside the canvas tent, step out, and explore with a real kerosene lantern as your only light.
Something else is out there. In this version it is **never seen clearly, only hinted at**.
A full chase and jump scare is planned for a LATER version (see section 8): leave hooks, build none of it now.

## 2. Decisions already made (do not re-ask)

like the 1870s ruins). If unsure whether something existed in 1957, leave it out. The menu should also use a
period-appropriate look (for example a 1950s typewriter or park-signage style), not a modern UI style.

## 3. How the code is laid out now

`source/build.mjs` bundles `source/src/*.js` into one HTML file, using `source/template.html` (which holds the menu).
All in `source/src/`:

- `main.js`: WebGPU setup, the night look (`LOOK_OWN`), the list of meshes (their ids are commented just above it),
  the eclipse clock (`ECLX = 4.5`, the speed-up), walking, collision and the camera, the lantern (carried, lifted,
  aimed, its light and shadows), the wake-up opening, the render loop and input. `POSES` are the dev viewpoints,
  `FLY` the benchmark path.
- `world.js`: the terrain (winding canyon, side pockets, the road out, the walls), where plants and rocks go, the camp
  layout and the made objects (tent, truck, trailer, chair, camp gear, the lantern).
- `ruins.js`: the nine 1870s homes, the supper stages, the traces of later visitors, the picnic table with the papers,
  the camera on its tripod, the park sign, the trail marker.
- `shaders.js`: all the GPU code (WGSL): a material per part id (`prop()`), rock and sand, lighting (moon, fire,
  lantern, soft shadows), sky and eclipse, fog, plants, the final picture.
- `sky.js`: the real stars for 7 November 1957 and Sputnik 2's pass.
- `paper.js`, `paperart.js`: where the papers lie, and their generated pictures (newspapers, photos, park map, star
  chart, the observer's handwriting).
- `audio.js`: the M2 stand-in sounds (M4 rewrites this file).
- `quality.js`: the Low/Medium/High levels. `math.js`: shared helpers.
- `dev.js`: the dev tools, only in `dev.html`.

## 4. Milestones

Each milestone ends with a build that runs. Stop and show the owner before moving on.

### M1: Land look, camp, sky (look-around only)  (done)
Goal: you can stand at the tent and look around a believable desert night. Free camera is fine for M1.
1. Remove all water: surface from below, caustics, bubbles, depth-blue fog, god rays, blue tint.
2. Replace fog with thin dry night air: slight cool blue haze, short fog distance at ground level, no scattering color shift. Keep the distance fade so the edge of the world never shows.
3. Sky: black-blue gradient, dense stars, a Milky Way band, a low moon in the west (now the eclipsed full moon, see Time and light), all procedural. One lighting source from the moon (reuse the sun shadow map, with the moon direction).
4. Re-color terrain to red-orange sandstone and pale sand, lit only by moonlight. Dark overall. Rocks must still be readable.
5. Camp set at the start pose (colors as in the decisions table): low campfire (warm flickering light and glow), canvas tent (enterable shape, open flap), a 1950s pickup towing a rounded metallic camper trailer, folding chair, cooler and gear. Clear the terrain there using the existing `CLEARS` mechanism so props sit on flat ground.
6. Lantern: a visible procedural 1950s kerosene lantern in the lower right of the view, and a single warm point light at its flame, with short range and fast falloff, flicker, and sway. No shadows from it in M1.
7. Plants: scatter juniper, pinyon, sagebrush, yucca, prickly pear and cacti by simple procedural meshes, replacing the kelp.
8. Keep `dev.js` benchmark working. Check frame time before moving on.

Acceptance: a screenshot from the tent door shows camp lit by fire, a starry sky with moon, dark red cliffs in the distance, no water look anywhere.

### M2: Walking, canyon, boundaries  (done)

Dev build only: keys 1-6 viewpoints, G free camera, H stats, T night-look sliders, F/B fly and benchmark.

2. Keep rock collision (`collide()`), tuned for a standing capsule.
3. Lantern bob and sway tied to footsteps. Footstep sounds: sand versus rock, based on slope or surface type.
4. Shape the map edge with canyon walls and cliffs so you cannot walk out. Remove the 150 m radius clamp and the depth clamp.
5. Start inside the tent: short interior, then the wake sequence from the decisions table (radio clicks on, clatter, crickets stop) and the player steps out through the flap. Interior as in the decisions table.

- Keep large shapes readable at distance (mesas, arches) so the world feels huge and empty.
